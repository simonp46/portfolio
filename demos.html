Featured Demo

Clinical Profile Agent

Diseñé e implementé un MVP de producción llamado ClinicalProfileAgent, un copiloto de documentación clínica asistida por IA para terapeutas respiratorios y profesionales de salud. El sistema recibe o sincroniza sesiones, procesa transcripciones, desidentifica contenido sensible, genera borradores estructurados con modelos de lenguaje, crea documentos clínicos en formatos PDF/DOCX y centraliza el flujo de revisión profesional en un dashboard web responsive.

La solución fue desarrollada en un monorepo con FastAPI, SQLAlchemy, Alembic, PostgreSQL, Celery, Redis, Next.js 15, TypeScript y Tailwind, incluyendo autenticación JWT, recuperación de contraseña por SMTP, integración OAuth con Google/Microsoft, observabilidad básica, pruebas automatizadas, Docker Compose, CI/CD con GitHub Actions y despliegue productivo en servidor cloud.
